# 🚀 Quick Start: Timer Polaris

## Pasos Rápidos para Empezar

### 1️⃣ Conectar Hardware
```
Timer Console → Cable RS-232 → Adaptador USB → PC
```

### 2️⃣ En la Aplicación
1. Abre un evento
2. Ve a **"Captura"**
3. Cambia modo a **"Timer Externo"**
4. Clic en **"Configurar Timer"**
5. Selecciona puerto COM
6. Clic en **"Conectar Timer"**

### 3️⃣ Capturar Tiempos
- Selecciona equipo
- El tiempo se captura automáticamente cuando el timer se detiene
- Ajusta penalizaciones
- Guarda el run

## ✅ Verificación

¿El badge dice **"Timer Conectado"** en verde? → Todo listo

## 🆘 Problemas?

- **No aparecen puertos?** → Presiona "Actualizar Lista"
- **No se conecta?** → Verifica que el cable esté en el Output Jack
- **No captura tiempos?** → Prueba START/STOP en el timer manualmente
